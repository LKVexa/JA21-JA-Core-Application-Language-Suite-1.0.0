# JA21-JA-Core-Application-Language-Suite-1.0.0

Study application language design through 10,000 records, 1,000 JA programs, and a 22-chapter textbook. JA Core brings types, ownership, effects, and module contracts together with feature catalogs, compiler and runtime specifications, lessons, and offline tools. A structured reference for educators, language designers, and application researchers.

The JA Core Application Language Suite presents a structured reference for application language design, with particular attention to types, ownership, effects, and module contracts. Its collection contains 10,000 normalized technical records and 1,000 source-faithful JA programs, organized across ten proficiency levels and ten validation classes. A 31-feature atlas and twenty corpus shards give readers multiple routes into the material, from individual examples to broader architecture questions.

The accompanying 22-chapter textbook explains application construction, language semantics, compiler and runtime architecture, evidence, certification concepts, and a capstone. A twelve-week curriculum, workbook, instructor guide, and starter project support teaching and practical exploration. Additional assets include a provisional grammar, language specification, compiler and runtime contracts, semantic operator registry, diagnostic catalogs, R12/MCRT schemas, and offline inspection tools. Source documents, manifests, and audit qualifications preserve the distinction between historical labels and current evidence.

This suite suits programming-language educators, application researchers, and compiler designers assessing proposed language contracts. The updated edition explicitly qualifies modeled metadata. Native parsing, compilation, execution, package management, and target conformance require further implementation and testing.

## Corpora and audit records

The supplied corpus layout is preserved under `payload/`. The `audit/` directory and [AUDIT_AND_UPGRADES.md](AUDIT_AND_UPGRADES.md) record source coverage, release changes, and evidence boundaries.

Historical source archives and source manifests remain provenance records. Current publication file hashes are listed in `PUBLICATION_SHA256.json`; licensing changes are recorded in `PUBLICATION_LICENSE_LEDGER.json`.
