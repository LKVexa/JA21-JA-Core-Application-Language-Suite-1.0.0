## Weekly rhythm

1. Read the assigned chapter.
2. Run structural inspection on ten positive and five diagnostic records.
3. Implement or model one feature-focused application.
4. Produce source, semantic, AST, R12, runtime, MCRT, validation, and limitation evidence.
5. Conduct the five-lens review.
