# Student Workbook — JA Core Application Language

Use this workbook with the technical textbook and script catalog. Do not mark modeled corpus outcomes as native execution.

## Chapter 1 — The Core Application Language as a JA21 Suite

**Features:** `module`

1. Record the selected script ID and corpus record ID.
2. Compute or verify the source SHA-256.
3. Summarize the source intent in two sentences.
4. Copy the semantic judgment and explain each environment, policy, type, effect, and capability term.
5. Draw the AST node and its child relation.
6. Record the R12 operator, dependencies, input/output hashes, state, and confidence.
7. Record the MCRT policy status, determinism class, causal parents, and certification status.
8. Identify one valid optimization and three invariants it must preserve.
9. Compare one positive and one diagnostic example.
10. Laboratory: Create an evidence map for a small console application and distinguish modeled corpus outcomes from native execution.

### Evidence checklist

- [ ] Source and hash
- [ ] Semantic worksheet
- [ ] AST sketch
- [ ] R12 record
- [ ] Runtime trace labeled modeled or native
- [ ] MCRT record
- [ ] Validation matrix
- [ ] Limitation statement
