# Governance Charter

## Mission

Maintain JA Core as a teachable, inspectable, air-gap-safe application-language suite whose publication claims never exceed its evidence.

## Stewardship roles

- **SOPHIA:** semantic and policy coherence.
- **CHARLOTTE:** grammar, AST, package, and interface coherence.
- **LANDON:** compiler, runtime, sandbox, and replay feasibility.
- **Professor:** curriculum, textbook, laboratories, and assessment.
- **Podium:** publication design, cataloging, release notes, and evidence visibility.

These names are review lenses within the workflow.

## Release gates

A release requires:
1. corpus record count and uniqueness;
2. source-hash verification;
3. script-pack count and catalog parity;
4. level, class, and feature coverage;
5. textbook and education completeness;
6. manifest verification;
7. Windows path-safety and ZIP integrity;
8. explicit distinction between modeled and native evidence.

## Change policy

Any change to source programs, semantic judgments, AST contracts, R12/MCRT records, schemas, or validation expectations must receive a new release version and migration note.
