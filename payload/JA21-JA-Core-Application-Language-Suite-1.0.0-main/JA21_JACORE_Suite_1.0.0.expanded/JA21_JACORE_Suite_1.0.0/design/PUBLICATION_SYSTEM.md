# JA21 Core Application Publication System

## Visual idea — “Application Atelier”

The publication treats a program as a crafted application artifact moving through layered benches: source, semantics, compiler, runtime, and evidence. The visual system is restrained and institutional rather than ornamental.

## Principles

1. **Evidence before decoration.** Record IDs, hashes, expected status, and trust boundaries remain visible.
2. **Layered navigation.** Blue denotes application structure, gold denotes transformation, green denotes validated structure, and red denotes diagnostics.
3. **Air-gap safety.** All content uses Markdown, JSON, CSV, Python standard library tools, and a local SVG cover.
4. **Print resilience.** Headings, labels, borders, and hierarchy still work in monochrome.
5. **Compact paths.** Directory and file names remain safe for common Windows extraction environments.

## Page hierarchy

- Suite title and profile
- Trust statement
- Primary deliverables
- Application architecture
- Evidence and validation
- Learning path
- Provenance
