# Role-Based Reading Paths

## Application developer
Read textbook Chapters 1–12, work through tracks 01–04, then complete the starter application.

## Language and compiler engineer
Read Chapters 1–7 and 15–19. Use the AST, semantic, R12, MCRT, and optimization fields in the technical corpus.

## Runtime engineer
Read Chapters 10–12 and 18–21. Focus on ownership, capabilities, async scheduling, sandbox evidence, host integration, and replay.

## Security reviewer
Read Chapters 10–12, 14, 18, and 20. Compare positive scripts with security, boundary, and negative classes.

## Educator
Use the twelve-week curriculum, workbook, instructor guide, and the level-balanced script catalog.

## Certification reviewer
Start with the validation report and conformance framework, then inspect all 25 certification scripts and their source-linked corpus records.
